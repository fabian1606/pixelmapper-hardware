# Front-panel fonts

Source data for the two bitmap fonts in `src/ui_font_data.c` (interface:
`src/ui_font.h`). The C file is generated by `tools/gen_fonts.py` from the
BDF files in this directory and is committed.

## Metrics

Glyphs are placed into the cell using the BDF `BBX` offsets and
`FONT_ASCENT`/`FONT_DESCENT`, so the baseline is the same for every glyph:

| Font | Cell | Ascent/descent | Cap height | x-height | Baseline row | Descender rows |
|------|------|----------------|------------|----------|--------------|----------------|
| `ui_font_8x16b` | 8x16 | 12/4 | rows 2..11 | rows 5..11 | 11 | 12..14 |
| `ui_font_6x8` | 6x8 | 7/1 | rows 1..6 | rows 3..6 | 6 | 7 |

The 5x8 font fits the 8-row cell exactly; descenders of `g j p q y` use the
single descender row 7 (as in the original font), nothing is clipped. The
generator aborts if any pixel would fall outside the cell.

## Regenerate

```sh
cd node/firmware/components/pm_ui
python3 tools/gen_fonts.py            # writes src/ui_font_data.c
python3 tools/gen_fonts.py --preview  # prints every glyph of both fonts as ASCII art
python3 tools/gen_fonts.py --check    # exit 1 if src/ui_font_data.c is out of date
```

Python >= 3.11, standard library only. Output is deterministic. The UI symbols
are defined in `gen_fonts.py` (`SYM_8x16`, `SYM_6x8`), either as ASCII art or
as a Unicode code point taken from the respective BDF.

## Code page and UI symbols

0x20..0x7E ASCII (from the BDF), 0x7F blank, 0x80..0x96 UI symbols, 0x97..0x9F
blank. "drawn" = drawn for this project in `gen_fonts.py`; otherwise the glyph
is taken from the source BDF (Terminus for 8x16, misc-fixed 5x8 for 6x8) at
the given code point.

| Code | Macro | Description | 8x16 origin | 6x8 origin |
|------|-------|-------------|-------------|------------|
| 0x80 | `UI_G_OUT` | right triangle: output | drawn | drawn |
| 0x81 | `UI_G_IN` | left triangle: input | drawn | drawn |
| 0x82 | `UI_G_DASH` | en dash: port off | Terminus U+2013 | 5x8 U+2013 |
| 0x83 | `UI_G_REMOTE` | circular arrow (clockwise): changed remotely | drawn | drawn |
| 0x84 | `UI_G_DOWN` | down arrow: update/download | Terminus U+2193 | 5x8 U+2193 |
| 0x85 | `UI_G_CHECK` | check mark | drawn | drawn |
| 0x86 | `UI_G_BKSP` | backspace (erase left), uses full cell width | drawn | drawn |
| 0x87 | `UI_G_SPACE` | visible space (open box) | drawn | drawn |
| 0x88 | `UI_G_WARN` | warning triangle with ! | drawn | drawn |
| 0x89 | `UI_G_LINK` | link up (solid up triangle) | drawn | 5x8 U+25B2 |
| 0x8A | `UI_G_NOLINK` | cross: no link | drawn | drawn |
| 0x8B | `UI_G_LOCK` | padlock | drawn | drawn |
| 0x8C | `UI_G_DOT` | filled circle: staged | Terminus U+25CF | 5x8 U+25CF |
| 0x8D | `UI_G_SUB` | single right angle quote: submenu | Terminus U+203A | 5x8 U+203A |
| 0x8E | `UI_G_ELLIPSIS` | horizontal ellipsis, uses full cell width | Terminus U+2026 | 5x8 U+2026 |
| 0x8F | `UI_G_MICRO` | micro sign | Terminus U+00B5 | 5x8 U+00B5 |
| 0x90 | `UI_G_RARROW` | right arrow | Terminus U+2192 | 5x8 U+2192 |
| 0x91 | `UI_G_LARROW` | left arrow | Terminus U+2190 | 5x8 U+2190 |
| 0x92 | `UI_G_UARROW` | up arrow | Terminus U+2191 | 5x8 U+2191 |
| 0x93 | `UI_G_LSUB` | single left angle quote | Terminus U+2039 | 5x8 U+2039 |
| 0x94 | `UI_G_MIDDOT` | middle dot | Terminus U+00B7 | 5x8 U+00B7 |
| 0x95 | `UI_G_IDENT` | sun / identify (circle with rays) | drawn | drawn |
| 0x96 | `UI_G_BLOCK` | full block (cursor), whole cell | Terminus U+2588 | drawn |

Drawn symbols are aligned with the text: in 8x16 they sit in the cap-height
band (rows 2..11, bottom on the baseline) with mostly 2-px strokes; in 6x8 they
sit in rows 1..6. Column 7 (8x16) / column 5 (6x8) is kept empty except for
backspace, ellipsis and the full block.
